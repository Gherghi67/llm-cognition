On 2026-11-10 the user asked that their presentation slides not read as AI-generated ("reader should not know that this is AI generated"). The rewrite that satisfied this used:
- plain descriptive titles instead of slogan or binary-contrast lines ("One bias test, run on all nine layers", not "Same test, nine layers. Only the structure changes.");
- matter-of-fact pen annotations;
- speaker notes as terse first-person cue bullets, with no coaching meta like "Say:" or "If asked:";
- the prose-hygiene rules.

**Why:** the deck is presented and graded as the user's own work, and the speaker notes are visible to anyone who opens a Slides artifact.

**How to apply:** draft course text in this register from the start. Separately, the LLMs & Cognition course asks that the final project report not be written with LLMs and requires an LLM-disclosure section in it. When the deliverable is that report, say so in one line instead of working around it. See [[teams-via-chrome-mine]] for where the course rules came from.
